# Student Performance Prediction System

## Project Overview

The Student Performance Prediction System is a machine learning project
that predicts a student's final marks using academic and study-related
features.

## Objective

The objective of this project is to analyze student data and build a
machine learning model that can predict final examination performance.

## Input Features

- Attendance percentage
- Previous marks
- Study hours per day
- Assignments completed

## Target

- Final Marks

## Project Workflow

1. Data collection
2. Data inspection
3. Data preprocessing
4. Missing value handling
5. Duplicate removal
6. Invalid value checking
7. Exploratory Data Analysis
8. Feature selection
9. Train-test split
10. Machine learning model training
11. Prediction
12. Model evaluation
13. Data visualization
14. New student performance prediction

## Machine Learning Model

Linear Regression

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
